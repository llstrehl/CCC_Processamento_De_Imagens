# Notebooks

`treino_cnn.ipynb` treina a CNN no Google Colab a partir do `recortes.zip` gerado
por `python -m src.dataset`. Ele clona este repositório e chama o mesmo
`src/train.py` usado localmente, então o modelo que sai daqui funciona na
aplicação sem nenhum ajuste.

Ao final, baixe o arquivo e salve em `models/grain_cnn.keras`.
